## 🎯 游戏目标

每个关卡给出一个**输入信号**（或一组输入）和一个**输出端**。  
您需要放置红石元件（红石粉、中继器、火把、比较器、侦测器、红石块）搭建电路，使输出端信号的：

| 参数 | 说明 |
|------|------|
| **延迟 (delay)** | 信号从输入到输出经过的 tick 数 |
| **持续时间 (duration)** | 输出信号保持高电平的 tick 数 |

**完全等于**关卡目标值，即可过关。

## 🧱 红石元件

### 1. 红石粉 (Dust)

| 属性 | 说明 |
|------|------|
| 功能 | 基础导线，传递信号 |
| 延迟 | 每格 **1 tick** |
| 衰减 | 每格衰减 **1 点**强度（从 15 开始） |
| 方向 | 自动连接相邻导线/元件，**不可旋转** |
| 交互 | 点击已放置的红石粉无额外效果 |

**图示：**
```
🟥 红石粉连接路径
信号 → 🟥 → 🟥 → 🟥 → 输出
延迟: 1tick  1tick  1tick
强度: 15→14→13→12
```

---

### 2. 中继器 (Repeater)

| 属性 | 说明 |
|------|------|
| 功能 | 单向信号放大，恢复强度至 15 |
| 延迟 | **1~4 tick**（可调，档位值 + 1 tick） |
| 方向 | 背面输入，正面输出（**可旋转 R**） |
| 交互 | 点击已放置的中继器 **切换延迟档位**（1→2→3→4→1） |

**图示：**
```
背面 ← 🔁 正面 →
延迟档位: 1 → 2 tick
           2 → 3 tick
           3 → 4 tick
           4 → 5 tick
```

---

### 3. 红石火把 (Torch)

| 属性 | 说明 |
|------|------|
| 功能 | **信号反相器**（非门） |
| 逻辑 | 背面有信号 → 火把**熄灭**（输出 0）<br>背面无信号 → 火把**点亮**（输出 15） |
| 方向 | 火把头指向输出方向，杆部连接输入（**可旋转 R**） |
| 交互 | 点击已放置的火把无额外效果 |

**图示：**
```
背面无信号 → 🔥 点亮 → 输出 15
背面有信号 → 💨 熄灭 → 输出 0
```

---

### 4. 比较器 (Comparator)

| 属性 | 说明 |
|------|------|
| 功能 | 信号比较/运算 |
| 模式 | **比较模式**：主输入 ≥ 侧输入 → 直通信号<br>**减法模式**：输出 = 主输入 - 侧输入 |
| 方向 | 背面为主输入，两侧为侧输入，正面输出（**可旋转 R**） |
| 交互 | 点击已放置的比较器 **切换模式**（比较↔减法） |

**图示：**
```
        侧输入
          ↓
主输入 → 📊 → 输出
          ↑
        侧输入

比较模式: 主 ≥ 侧 → 直通
减法模式: 输出 = 主 - 侧
```

---

### 5. 侦测器 (Observer)

| 属性 | 说明 |
|------|------|
| 功能 | 检测前方信号**上升沿**（从无到有） |
| 输出 | 从背面输出 **2 tick 短脉冲**（强度 15） |
| 方向 | "脸"朝信号来源方向，背面输出（**可旋转 R**） |
| 交互 | 点击已放置的侦测器无额外效果 |

**图示：**
```
信号源 → 👁️ 脸朝信号 → 背面输出脉冲
检测到上升沿 → 输出 2 tick 脉冲
```

---

### 6. 红石块 (Block)

| 属性 | 说明 |
|------|------|
| 功能 | **永久信号源** |
| 输出 | 始终输出强度 **15** |
| 方向 | 无方向 |
| 交互 | 点击已放置的红石块无额外效果 |

**图示：**
```
🧱 红石块
始终输出 → 强度 15
无需输入，常亮电源
```

## 🎮 操作指南

### 放置与编辑

| 操作 | 效果 |
|------|------|
| **左键** 点击网格 | 放置当前选中的元件 |
| **右键** 点击网格 | 移除元件（橡皮擦功能） |
| **R 键** | 旋转当前选中元件（放置前） |
| **点击已放置的元件** | 中继器切换延迟档位 / 比较器切换模式 |

### 模拟控制

| 按钮 / 快捷键 | 效果 |
|------|------|
| ▶️ **播放** / **空格键** | 开始信号模拟 |
| ⏸️ **暂停** / **空格键** | 暂停模拟 |
| 🔄 **重置** | 重置所有信号状态 |
| ⏭️ **单步** | 前进 1 tick |

### 工具

| 按钮 | 效果 |
|------|------|
| 🔄 **旋转(R)** | 旋转当前选中元件方向 |
| 💾 **存档** | 下载当前进度 JSON 文件 |
| 📂 **读档** | 上传存档文件恢复进度 |

## 📂 关卡定义 (JSON)

### 完整格式

```json
{
  "levels": [
    {
      "name": "关卡名称",
      "desc": "关卡描述",
      "cols": 12,
      "rows": 8,
      "input": {
        "x": 1,
        "y": 4,
        "duration": 10,
        "strength": 15
      },
      "inputs": [
        {
          "x": 1,
          "y": 2,
          "duration": 10,
          "strength": 15,
          "delay": 0
        },
        {
          "x": 1,
          "y": 6,
          "duration": 10,
          "strength": 15,
          "delay": 5
        }
      ],
      "output": {
        "x": 10,
        "y": 4
      },
      "target": {
        "delay": 4,
        "duration": 10
      },
      "components": ["dust", "repeater"],
      "limits": {
        "repeater": 2
      },
      "hint": "提示文字",
      "par": 10,
      "logic": "not",
      "preplaced": [
        {
          "x": 5,
          "y": 3,
          "type": "block",
          "direction": 0,
          "delay": 1,
          "mode": "compare"
        }
      ]
    }
  ]
}
```

### 字段详解

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | 关卡名称 |
| `desc` | string | ✅ | 关卡描述 |
| `cols` | int | ✅ | 网格列数 |
| `rows` | int | ✅ | 网格行数 |
| `input` | object | 二选一 | 单输入配置 `{x, y, duration, strength}` |
| `inputs` | array | 二选一 | 多输入配置数组 `[{x, y, duration, strength, delay}]` |
| `output` | object | ✅ | 输出点 `{x, y}` |
| `target` | object | ✅ | 目标 `{delay, duration}` |
| `components` | array | ✅ | 可用元件列表，可选值：`dust`/`block`/`torch`/`repeater`/`comparator`/`observer` |
| `limits` | object | ❌ | 元件数量限制 `{元件类型: 数量}` |
| `hint` | string | ✅ | 通关提示 |
| `par` | int | ❌ | 推荐元件数（默认 10），影响评星 |
| `logic` | string | ❌ | 逻辑门类型 `"not"`/`"or"`/`"and"`，显示对应介绍 |
| `preplaced` | array | ❌ | 预放置元件，玩家无法移除 |

### preplaced 元件格式

```json
{
  "x": 5,
  "y": 3,
  "type": "block",
  "direction": 0,    // 0=右 1=下 2=左 3=上
  "delay": 1,        // 中继器延迟档位
  "mode": "compare"  // 比较器模式: "compare" 或 "subtract"
}
```

## 🚀 运行与生成

### 环境要求

- Python 3.6+（用于生成器脚本）
- 现代浏览器（Chrome / Firefox / Edge / Safari）

### 1. 使用生成器脚本

```bash
# 基本用法
python gen_redstone_game.py <关卡定义文件.json> [输出文件.html]

# 示例
python gen_redstone_game.py levels_example.json index.html

# 不指定输出文件，默认生成 redstone-puzzle.html
python gen_redstone_game.py levels_example.json
```

### 2. 直接运行

用浏览器打开生成的 `index.html` 文件即可开始游戏。  
所有进度自动保存在浏览器本地存储中。

## 🔧 技术栈

| 组件 | 技术 |
|------|------|
| 前端 | 纯 HTML + CSS + JavaScript |
| 渲染 | Canvas 2D 绘制 |
| 模拟引擎 | 基于 tick 的离散信号模拟 |
| 存储 | localStorage + JSON 导入/导出 |
| 依赖 | 无外部依赖 |

### 信号模拟机制

- **Tick 周期**: 120ms
- **信号强度**: 0 ~ 15
- **衰减**: 红石粉每格衰减 1 点
- **延迟计算**: 每个元件贡献固定 tick 延迟
- **脉冲检测**: 侦测器检测上升沿
