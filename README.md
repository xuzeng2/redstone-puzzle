# ⚡ 红石逻辑解谜

> 在网格上搭建红石电路，精确匹配延迟与脉冲宽度，用红石元件实现逻辑门。

这是一个基于 **Python 关卡生成器** + **纯前端 HTML** 的交互式红石电路解谜游戏。你可以在网格上自由放置红石元件，模拟信号传播，挑战各种逻辑关卡。

---

## 🎯 游戏目标

每个关卡给定一个**输入信号**和一个**输出端**。你需要搭建电路，使输出端信号的：

- **延迟 (Delay)** —— 信号从输入到输出经过的 tick 数
- **持续时间 (Duration)** —— 信号保持高电平的 tick 数
- **信号强度 (Strength)** —— 可选目标

**全部精确匹配**关卡目标值，即可过关。

---

## 🧱 支持的元件

| 元件 | 功能 |
|------|------|
| 红石粉 | 导线，每格 1 tick 延迟，强度衰减 1 |
| 中继器 | 单向放大，1~4 tick 可调延迟 |
| 红石火把 | 信号反相器（非门） |
| 比较器 | 比较 / 减法模式 |
| 侦测器 | 检测上升沿，输出 2 tick 脉冲 |
| 红石块 | 永久信号源（强度 15） |
| 粘性活塞 | 可以推拉方块 |
---

## 🎮 操作方式

| 操作 | 效果 |
|------|------|
| **左键** 点击网格 | 放置当前选中的元件 |
| **右键** 点击网格 | 移除元件 |
| **R 键** | 旋转元件方向 |
| **点击已放置的元件** | 切换中继器档位 / 比较器模式 |
| **空格键** | 播放 / 暂停模拟 |

---

## 🚀 快速开始

### 1. 直接玩

用浏览器打开 `redstone-puzzle.html`，即刻开始游戏。

### 2. 生成自定义关卡

```bash
python gen_redstone_game.py levels_example.json redstone-puzzle.html
```

### 3. 自定义关卡定义

```json
{
  "levels": [
    {
      "name": "我的关卡",
      "desc": "描述",
      "cols": 12,
      "rows": 8,
      "input": {"x": 1, "y": 4, "duration": 10, "strength": 15},
      "output": {"x": 10, "y": 4},
      "target": {"delay": 8, "duration": 10},
      "components": ["dust", "repeater"],
      "limits": {"repeater": 2},
      "hint": "提示文字",
      "par": 10
    }
  ]
}
```
